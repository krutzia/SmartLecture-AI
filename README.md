# SmartLecture AI

AI study buddy that turns lectures into summaries, flashcards, quizzes, and a chat tutor.

## Getting started

1. Install dependencies:
   - `npm install` (or `bun install`)
2. Copy `.env.example` to `.env` and fill in the values.
3. Start the dev server:
   - `npm run dev`

## Environment variables

Set these in your Supabase Edge Functions environment:

- `AI_API_URL` — Chat completions endpoint (e.g. `https://api.openai.com/v1/chat/completions`).
- `AI_API_KEY` — API key for the AI provider.
