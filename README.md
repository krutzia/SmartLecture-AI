## 📖 Overview

SmartLecture AI is an AI-powered study companion that converts lecture materials into interactive learning resources.

Upload a lecture PDF or video, and the application automatically generates concise summaries, mind maps, flashcards, quizzes, transcripts, and provides an AI tutor to help reinforce learning.

---

## ✨ Features

- 📄 Upload lecture PDFs and videos
- 📝 AI-generated lecture summaries
- 🧠 Interactive mind maps
- 🃏 Flashcard generation
- ❓ AI-generated quizzes
- 💬 AI Study Buddy chat
- 📚 Transcript viewer
- 📊 Analytics dashboard
- 📤 Export study material
- 🌙 Modern responsive UI

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/krutzia/SmartLecture.git
```

Move into the project

```bash
cd SmartLecture
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

Run locally

```bash
npm run dev
```

Open

```
http://localhost:8080
```
